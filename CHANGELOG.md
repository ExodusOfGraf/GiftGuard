### Полная сквозная E2E верификация (14 этапов)

Проведён полный end-to-end тест жизненного цикла розыгрыша на боевом сервере с реальной криптографией:
1. **Аутентификация Telegram**: генерация валидных подписей `initData` (HMAC-SHA256) для организатора и 3 участников.
2. **Создание розыгрыша**: `POST /api/giveaways` -> создан черновик розыгрыша.
3. **Установка приза**: `POST /api/giveaways/{id}/prize` -> привязан `telegram_gift` ("Plush Pepe #7421", ~72 TON).
4. **Публикация**: `POST /api/giveaways/{id}/publish` -> генерация криптографического seed commitment, статус переведён в `active`.
5. **Публичный предпросмотр**: `GET /api/public/giveaways/{id}` -> возвращает розыгрыш с призом и условиями.
6. **Участие пользователей**: 3 участника успешно зарегистрировали билеты с расчётом anti-farm risk score.
7. **Идемпотентность**: повторный запрос на участие возвращает существующий билет со статусом 200 без дублирования.
8. **Конфиденциальность (Privacy-preserving)**: `GET /participation/me` возвращает участнику только статус и номер билета; `risk_score` надёжно скрыт от участников.
9. **Инспектор организатора**: `GET /participants` возвращает список участников с прозрачными сигналами антифрода.
10. **Аналитика кампании**: `GET /analytics` возвращает точное распределение участников по категориям риска.
11. **Дедлайн**: наступление времени завершения розыгрыша (`ends_at`).
12. **Provably Fair Draw**: `POST /giveaways/{id}/draw` -> детерминированный выбор 2 победителей через HMAC-SHA256 rejection sampling, расшифровка секретного seed, фиксация канонического хэша участников.
13. **Публичная верификация**: `GET /api/public/giveaways/{id}/verification` -> публичный доступ к доказательству честности (`verified: true`, канонический снэпшот, хэш, энтропия, финальный seed, победители).
14. **Независимая верификация сервером**: `POST /api/public/giveaways/{id}/verify` подтвердила математическую корректность розыгрыша (`verified: true`).

1. **Backend (Python 3.12 / FastAPI / SQLAlchemy 2.0 Async / Alembic / Redis / ARQ)**:
   - Модели данных (`app/models.py`): `User`, `Giveaway`, `GiveawayRequirement`, `Prize`, `Participation`, `Draw`, `Winner`.
   - Жизненный цикл розыгрыша: `draft` → `scheduled` / `active` → `locked` → `drawing` → `completed` / `cancelled`.

   - Anti-Farm Engine (`app/antifraud/`): 6 правил (`ParticipationBurstRule`, `InstantJoinRule`, `RequirementCompletionSpeedRule`, `DuplicatePatternRule`, `NewInteractionRule`, `ReferralAnomalyRule`), оценка 0–100, уровни LOW/MEDIUM/HIGH.
   - Provably Fair Draw Protocol (`app/draw/protocol.py`): алгоритм `giftguard-v1` с предварительным `commitment_hash` (SHA-256), `participant_snapshot_hash`, внешней энтропией, шифрованием `secret_seed` через Fernet и выбором победителей через rejection sampling без повторений.
   - Авторизация WebApp (`app/auth.py`): валидация `initData` по HMAC-SHA256, проверка `auth_date` и защита от replay.
2. **Telegram Bot (`aiogram 3`)**:
   - Реализован бот с FSM-машиной для создания драфтов (`/create`), командами `/start`, `/help`, `/my_giveaways`, `/giveaway <id>` и inline-кнопкой участия.
3. **Frontend (`Next.js` / TypeScript)**:
   - Базовый дашборд организатора, форма создания, страницы просмотра участников и верификации результатов.
4. **Тесты (`pytest`)**:
   - Покрыты тестами протокол честного розыгрыша, правила антифрода, валидация auth Telegram WebApp, проверка подписки и переходы статусов.

## [0.2.0-frontend] — 2026-09-23

### Реализация Telegram Mini App и панели управления

#### Added
- **Дизайн-система Telegram Mini App (`frontend/src/app/globals.css`)**:
  - Поддержка нативных переменных Telegram WebApp (`--tg-theme-*`) со сбалансированной темной и светлой палитрой.
  - Стили карточек с эффектом glassmorphism, бейджи статусов розыгрышей (`Draft`, `Scheduled`, `Active`, `Locked`, `Drawing`, `Completed`, `Cancelled`).
  - Градация бейджей риска Anti-Farm: `LOW` (зелёный), `MEDIUM` (янтарный), `HIGH` (красный/розовый).
  - Компоненты модального окна и выдвижной панели для инспекции участников.
- **Интеграция с Telegram WebApp SDK (`frontend/src/lib/telegram.ts`)**:
  - Автоматическая инициализация (`ready()`, `expand()`), тактильный отклик (`hapticImpact`, `hapticNotification`), безопасное извлечение `initData` и данных пользователя.
- **Компоненты интерфейса**:
  - `Navbar` (`frontend/src/components/Navbar.tsx`): адаптивная шапка с логотипом, статусом подключения к Telegram и быстрой навигацией.
  - `StatusBadge` (`frontend/src/components/StatusBadge.tsx`): визуальные бейджи этапов жизненного цикла розыгрыша.
  - `RiskBadge` (`frontend/src/components/RiskBadge.tsx`): бейдж уровня риска с баллом (0–100).
  - `ParticipantModal` (`frontend/src/components/ParticipantModal.tsx`): интерактивная модалка детальной инспекции участника с полной расшифровкой эвристических сигналов антифрода (`+25 burst`, `+18 completion speed`, `+15 first interaction` и т.д.) и результатами проверки каналов.
- **Мастер создания розыгрыша (`frontend/src/app/giveaways/new/page.tsx`)**:
  - 4-шаговая форма: базовые параметры (с быстрыми пресетами длительности: +24h, +3d, +7d), призы (Telegram Gift, Collectible, TON NFT, Custom с оценкой в TON), подписки на каналы (динамический список `@channel`), переключатель отсева HIGH-risk аккаунтов.
- **Адаптивный дашборд организатора (`frontend/src/app/dashboard/page.tsx`)**:
  - Сводные метрики кампаний, вкладки фильтрации (All, Active, Draft, Completed), карточки розыгрышей с таймерами и быстрыми действиями.
- **Двусторонний экран розыгрыша (`frontend/src/app/giveaways/[id]/page.tsx`)**:
  - Автоматическое определение роли (владелец / участник).
  - Для организатора: управление публикацией/отменой, запуск честного розыгрыша по окончании дедлайна, виджет аналитики аудитории.
  - Для участника: карточка приза, чеклист каналов с кнопками перехода в Telegram, кнопка «Участвовать» с проверкой подписок и отображением билета с UUID.
- **Инспектор участников и антифрода (`frontend/src/app/giveaways/[id]/participants/page.tsx`)**:
  - Поиск по username/ID, фильтрация по статусу выполнения условий и уровню риска, вызов модалки инспектора по клику на участника.
- **Публичная страница результатов и Provably Fair верификатор (`frontend/src/app/giveaways/[id]/results/page.tsx`)**:
  - Пьедестал победителей, криптографический манифест (Commitment Hash, Snapshot Hash, Entropy, Secret Seed, Final Seed).
  - Интерактивная кнопка проверки честности с 4-шаговым чеклистом и визуальным статусом `VALID ✓`.

#### Changed (Backend Support)
- **`backend/app/schemas.py`**:
  - Добавлены `RequirementRead`, `PrizeRead`, `PublicGiveawayRead`.
  - `GiveawayRead` дополнен связанными данными приза и требований для устранения лишних HTTP-запросов.
- **`backend/app/api/main.py`**:
  - Добавлен публичный эндпоинт `GET /api/public/giveaways/{giveaway_id}` для предпросмотра розыгрыша участниками без прав организатора.
- **`backend/app/repositories.py`**:
  - Оптимизирован метод `list_for_owner` через `selectinload` для требований и призов.

## [0.3.0-bot-ux] — 2026-09-23

### Модернизация UX Telegram-бота (Deep Linking, карточки, приватность, визард)

#### Added
- **Поддержка Deep Linking (`/start gw_<id>`)**:
  - Распознавание ссылок на розыгрыши из каналов (`https://t.me/GiftGuardBot?start=gw_<giveaway_id>`).
  - Мгновенный вывод карточки розыгрыша при переходе без лишних команд.
- **Информативная карточка розыгрыша (`format_giveaway_card`)**:
  - Наглядное отображение приза (тип, название, ориентировочная стоимость в TON), количества победителей, статуса, дедлайна с обратным отсчетом и обязательных каналов для подписки.
  - Кнопки быстрого перехода в каналы, кнопки «🔍 Проверить подписку», «🎁 Участвовать», «🌐 Открыть в Mini App» и «↗️ Поделиться».
- **Интерактивный пошаговый FSM-визард создания розыгрыша (`/create`)**:
  - Инлайн-клавиатуры для выбора типа приза (`Telegram Gift`, `Collectible`, `TON NFT`, `Custom`).
  - Быстрые пресеты длительности (`24 часа`, `3 дня`, `7 дней`) или ввод количества часов.
  - Пресеты победителей (`1`, `3`, `5`, `10`).
  - Пошаговое добавление обязательных каналов (`@channel`) с динамическим списком.
  - Тумблер исключения High-Risk аккаунтов (`exclude_high_risk`).
  - Автоматическая генерация готовой ссылки для шеринга в каналах.
- **Команда ручного подведения итогов (`/draw <id>`)**:
  - Доступна организатору после наступления дедлайна прямо из чата с ботом.
- **Модульные тесты бота (`tests/test_bot_ux.py`)**:
  - Парсинг deep link параметров (`gw_<uuid>`).
  - Расчет обратного отсчета дедлайна.
  - Корректность верстки карточки розыгрыша и клавиатуры.
  - Тест сокрытия внутренних оценок риска от участников.

#### Changed
- **Защита приватности антифрода**:
  - В соответствии со спецификацией, бот больше не выводит участникам числовые оценки `risk_score` и уровни `risk_level`, сохраняя конфиденциальность антифрод-модели и исключая зондирование фермерами.
  - Участник видит статус `PASSED ✓`, номер персонального билета (UUID), время розыгрыша и напоминание о механизме Provably Fair.
- **Оптимизация `EligibilityService.check`**:
  - Параметр `participation` сделан опциональным, что позволило вызывать предварительную проверку условий подписки до сохранения билета.
